Radar Viewer Privacy Policy

LanDen Labs · Last updated: 25-Nov-2026

Summary

Radar Viewer is a desktop application that shows public weather radar data on a map. It does not collect, store, sell or share any personal information. There are no user accounts, no analytics, no telemetry, no advertising and no crash reporting. LanDen Labs runs no servers that the application talks to.

Information we collect

None. Radar Viewer does not send any information about you or your use of the application to LanDen Labs.

Network connections

To show radar data and maps, the application downloads files directly from these third-party public services:

ServicePurpose
EUMETNET Open Radar Data S3 cache (CloudFerro, ECMWF)MeteoSwiss radar data
Unidata NEXRAD Level II bucket on Amazon Web Services (AWS)NWS NEXRAD radar data
Esri ArcGIS Online, OpenStreetMap, OpenTopoMap, swisstopoBasemap tiles, depending on the basemap you pick

As with any web request, these services receive your IP address, a User-Agent string that names the application and its version (for example qt-radar-viewer/1.01.01), and the files requested. The map tiles requested reveal the area you are viewing. These services handle that information under their own privacy policies. LanDen Labs does not control them and receives none of this data. Choosing None as the basemap stops all tile requests.

Data stored on your computer

  • Preferences: window layout, selected radar site, product, elevation, basemap, display options, and the last map position and zoom. They are saved with Qt's standard settings storage (the macOS preferences folder, the Windows registry, or a configuration file on Linux) so the application can restore them next time.
  • Cache: downloaded radar files and map tiles are kept in the operating system's cache folder to speed up later viewing. Radar files older than 2 days are deleted automatically. The radar cache is capped at 2 GB and the tile cache at 200 MB.
  • Files you save: PNG images or radar data files that you choose to save go only to the location you pick.

This data never leaves your computer. You can delete it at any time by removing the cache folder and the application's settings.

Local files

Files you open with File → Open or on the command line are read locally and are not uploaded anywhere.

Children's privacy

Radar Viewer collects no information from anyone, including children under 13.

Changes to this policy

If this policy changes, the updated version will be posted on this page with a new "Last updated" date.
